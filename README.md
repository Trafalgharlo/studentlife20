# Student Life

Адаптивный Telegram Mini App на HTML, CSS и JavaScript без сборки и серверных зависимостей.

## Возможности

- Главная страница со сводкой текущего дня и переходами в шесть разделов.
- Расписание: дни недели, время начала и окончания, аудитория, преподаватель.
- Напоминания: дата, время, заметки и отметка выполнения.
- Общага с друзьями: дела, ответственные, даты и отметка выполнения.
- Рандомайзер блюд: собственный список, ингредиенты, рецепт и случайный выбор без немедленного повторения при наличии нескольких блюд.
- Качалка: упражнения, даты, подходы, повторения и выполнение.
- Финансы: доходы, расходы, категории и баланс в тенге за всё время.
- Добавление, редактирование, удаление с подтверждением и пустые состояния во всех разделах.

## Данные и ограничения прототипа

Начальные примеры отмечены «Демо», включая отредактированные примеры. Новые записи не имеют этой метки. Сводка и баланс учитывают демонстрационные записи, пока они не удалены.

Данные сохраняются в localStorage текущего браузера (ключ `student-life:v1`). Это локальное хранилище, не база данных и не резервная копия: очистка данных браузера удалит записи. При недоступном хранилище приложение сообщает об ошибке, изменения остаются только до закрытия страницы. При повреждённых данных показываются демо-примеры. Даты зависят от локального времени устройства.

Общага пока представляет локальный список дел с именами ответственных. Приглашения, совместное редактирование, синхронизация между устройствами и уведомления через бота не подключены. Напоминания — список задач, а не фоновая рассылка. Для этих возможностей нужен отдельный сервер.

## Локальный запуск

Требуется Node.js 20 или новее:

```sh
node preview.cjs
```

Открыть http://127.0.0.1:4175. Сервер доступен только на локальном компьютере.

## Проверка

```sh
npm install
npx playwright install chromium
npm test
```

Тест сам запускает локальный сервер на порту 4175: перед тестом остановите отдельный сервер предпросмотра. Можно использовать установленный Edge, задав переменную `TEST_BROWSER_CHANNEL=msedge`.

Браузерные проверки покрывают CRUD всех разделов, сохранение после перезагрузки, выполнение задач, отмену удаления, некорректное время пары, рандомайзер, безопасный вывод HTML, повреждённое хранилище, тёмную тему, мобильную ширину и интеграцию с имитацией Telegram SDK. Скриншоты `desktop-preview.png` и `mobile-preview.png` создаются локально; новые файлы предпросмотра исключены из Git. Снимки, ранее добавленные в репозиторий, сохраняются. Реальное поведение WebView следует дополнительно проверить в Telegram на Android/iOS.

## Telegram Mini Apps

Подключён официальный SDK: `ready()`, `expand()`, нативная кнопка «Назад», смена темы и безопасные отступы. Приложение также работает в обычном браузере. Пользовательские данные не отправляются на сервер. SDK Telegram и необязательный шрифт Google Fonts загружаются по HTTPS; при недоступности шрифта используется системный.

Документация: https://core.telegram.org/bots/webapps

Токены не нужны для текущего интерфейса. Никогда не добавляйте токен бота в HTML/JS или репозиторий. При добавлении серверных функций храните секреты в серверных переменных окружения и проверяйте Telegram `initData` на сервере; клиентские данные не являются подтверждением личности.

После одобрения и слияния PR можно подключить production URL по HTTPS в BotFather. Создание PR само по себе не означает публикацию; существующая интеграция Vercel может автоматически создать preview для ветки.
