# Student Life

Telegram Mini App: расписание и ДЗ, напоминания, блюда с КБЖУ, тренировки «верх/низ» и финансы. Интерфейс работает без сборки, в Telegram и обычном браузере. Сервер уведомлений рассчитан на Vercel Hobby + Supabase.

## Что работает

### Качалка

Начальный личный план: верх — понедельник/четверг, низ — вторник/пятница, начало в 17:30. Это заданный пользователем график, не демо. Упражнения пользователь добавляет сам. Название, тип, день и время можно изменить.

В одной тренировке несколько упражнений, у каждого несколько подходов. Галочка «Упражнение с доп. весом» показывает поле килограммов; при снятии вес обнуляется. Кнопка «Записать результат» сохраняет фактические повторения, вес и выполнение каждого подхода для конкретной даты. План повторяется, результаты разных недель не перезаписывают друг друга. Стрелки недели позволяют просматривать прошлые результаты. Журнал остаётся доступен для редактирования даже после удаления плана тренировки или изменения дня.

### Что приготовить

Пользователь задаёт блюдо, число порций и состав. Для каждого ингредиента вводятся масса в блюде и КБЖУ на 100 г. Название и КБЖУ сохраняются в локальную библиотеку: при повторном выборе названия значения подставляются автоматически. Изменения библиотеки не меняют старые рецепты — в них сохранены собственные значения.

Расчёт: сумма `(масса / 100) × значение на 100 г` по каждому ингредиенту. Показываются всё блюдо, порция и 100 г исходных ингредиентов. Это расчёт по введённым данным, не справочник продуктов; изменение массы при приготовлении не учитывается. Значения примеров обозначены как демонстрационные. Рандомайзер выбирает из пользовательского списка без немедленного повторения при наличии нескольких блюд.

### Расписание и ДЗ

Для пары выбирается «Числитель», «Знаменатель» или «Каждую неделю». Один раз укажи любую дату известной недели и её тип в блоке «Числитель / знаменатель», затем сохрани чередование. Расписание переключается по календарю автоматически, в том числе на границе года; стрелки и переключатель типа показывают другие недели без изменения шаблонов. Старые пары после обновления считаются общими для обеих недель. Пока опорная неделя не подтверждена, чередование показывается предварительно, а сервер не включает уведомления для чередующихся пар. Можно добавить несколько ДЗ к конкретным датам пары, задать время сдачи и отметить выполнение. Проверяется соответствие даты дню недели и числителю/знаменателю пары. При изменении опорной недели проверь даты уже записанных невыполненных ДЗ. Сервер отправляет напоминания за 48, 24 и 10 часов **до начала пары**, независимо от времени сдачи ДЗ. Выполненные ДЗ исключаются. За 30 минут до каждой пары приходит «Пора выходить».

Сервер подхватывает события за последние 15 минут; более ранние события задним числом не отправляются. Перенос пары или удаление ДЗ учитывается после успешной синхронизации.

### Финансы

Вкладки: «Все», «Еда», «Одежда», «Мыльно-рыльное», «Прочее». Запись содержит покупку, сумму, категорию и дату; сегодня подставляется автоматически, можно исправить. Доходы сохраняются отдельно по типу и не включаются в расходы. Статистика по категориям и общей сумме рассчитывается за выбранную неделю (понедельник–воскресенье), рядом показана прошлая завершённая неделя. Суммы в тенге. Итог в Telegram — воскресенье, 21:00 в выбранном часовом поясе.

Раздел общаги удалён из интерфейса. Старые записи оставлены только в локальном хранилище для восстановления.

## Данные и миграция

Основные данные хранятся в localStorage (`student-life:v2`). При первом открытии переносится `student-life:v1`: сохраняются записи, старый текстовый состав блюд и результаты упражнений. Старый ключ не удаляется. Неизвестные категории расходов относятся к «Прочее», «Продукты» — к «Еда». Старые ингредиенты без чисел не получают выдуманное КБЖУ: нужно заполнить вручную.

Демонстрационные записи имеют метку «Демо» и участвуют в локальной статистике, но не отправляются боту. При редактировании можно явно выбрать «Это мои данные», чтобы снять метку и подключить уведомления для записи.

Очистка данных браузера удалит локальные записи. Это не полноценная облачная синхронизация. Для уведомлений после подключения на сервер загружаются только расписание, ДЗ, напоминания, операции финансов и часовой пояс; блюда, тренировки и старые дела общаги не загружаются. Сервер хранит последнюю успешно синхронизированную версию для каждого подтверждённого Telegram-пользователя. Другой браузер не скачивает эту версию автоматически.

## Локальный запуск

Node.js 20+:

```sh
node preview.cjs
```

Открыть http://127.0.0.1:4175. Локальный сервер возвращает понятный ответ «сервер уведомлений не настроен». Он не отправляет сообщений в Telegram.

## Проверка

```sh
npm install
npx playwright install chromium
npm test
```

Отдельно: `npm run test:unit` и `npm run test:browser`. Для установленного Edge можно задать `TEST_BROWSER_CHANNEL=msedge`. Браузерный тест сам запускает сервер на порту 4175: отдельно запущенный preview нужно остановить.

Покрытие: расчёт КБЖУ, сохранение библиотеки, упражнения/подходы/вес и изоляция недель, ДЗ и дата пары, категории и недельные суммы, миграция, экранирование HTML, мобильные размеры 320/390 px, тёмная тема, Telegram SDK и подключение/отключение уведомлений с имитацией API. Серверные тесты проверяют подпись Telegram, истечение сессии, подмену данных, входную валидацию, таймзоны, точные смещения уведомлений, отсечение демо и повторные вызовы worker с имитацией базы/Telegram.

Реальная Supabase-схема, планировщик и доставка на телефон требуют проверки после настройки инфраструктуры. Автотесты не отправляют реальные сообщения и не используют настоящие секреты. Проверка реального Telegram WebView на Android/iOS выполняется отдельно.

## Подключение бота и уведомлений на Vercel Hobby

1. Создать проект Supabase и выполнить `lib/schema.sql` в SQL Editor. Включены RLS и ограничения доступа: таблицы и служебные функции доступны только серверному service_role, не анонимным клиентам.
2. В Vercel → Project → Settings → Environment Variables добавить **только серверные** значения из `.env.example`: `TELEGRAM_BOT_TOKEN`, `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`, `CRON_SECRET`. `CRON_SECRET` — отдельная длинная случайная строка, не токен бота. Не добавлять значения в Git или клиентский JS. Токен в чат не присылать. Для preview использовать отдельные настройки/базу или не включать уведомления.
3. После просмотра и одобрения PR опубликовать проект. Framework Preset: **Other**, Build Command пустая, Output Directory: корень (`.`). Vercel обрабатывает `api/notifications.js` и `api/cron.js` как Node.js Functions. Не копировать только HTML: нужны также `lib/domain.js` и серверные файлы. В BotFather указать HTTPS production URL для Mini App существующего бота.
4. В Supabase включить Cron / pg_net. В Vault создать секреты `student_life_cron_url` (полный production URL с `/api/cron`) и `student_life_cron_secret` (тот же `CRON_SECRET`, что в Vercel). Значения вводятся только в Dashboard, не в репозиторий. Выполнить `lib/scheduler.sql` — запрос к защищённому worker каждую минуту. Проверить в Dashboard результаты Cron и HTTP-ответы: 200 означает успешный вызов, 401 — неверный секрет, 503 — ошибка настройки/доставки.
5. Открыть чат бота, нажать «Старт», затем открыть Mini App. В «Напоминаниях» проверить часовой пояс (для пользователя — `Asia/Qyzylorda`), нажать «Подключить Telegram» и разрешить боту сообщения. Для реальных напоминаний нужны собственные записи без метки «Демо». Изменения синхронизируются после сохранения; ошибки видны в разделе уведомлений. Данные передаются только по HTTPS, Telegram `initData` проверяется на сервере; сессии старше суток требуют заново открыть Mini App.
6. Для проверки создать свою задачу на несколько минут вперёд, закрыть Mini App и дождаться сообщения. Затем проверить реальные ДЗ и «Пора выходить». Проверить телефон: разрешения уведомлений, отсутствие mute / «Не беспокоить», звук чата бота.

Встроенный Cron Vercel Hobby допускает только ежедневный запуск и не подходит для этого сценария. Поэтому конфигурация не требует Vercel Pro: минутные вызовы выполняет Supabase. Следите за доступностью проекта, квотами Supabase и Vercel; отключённая/приостановленная база не отправит уведомления.

Источники: [лимиты Vercel Cron](https://vercel.com/docs/cron-jobs/usage-and-pricing), [Supabase Cron](https://supabase.com/docs/guides/cron), [pg_cron, pg_net и Vault](https://supabase.com/docs/guides/functions/schedule-functions).

### Доставка и звук

Worker выбирает события, наступившие за последние 15 минут, и прекращает устаревшие напоминания «выходить» к началу пары. База резервирует событие с защитой от параллельной отправки; успешные события повторно не отправляются. При ошибке до 5 попыток, не чаще чем раз в 2 минуты и только в окне актуальности. После длительного простоя события за пределами окна пропускаются. При редком сетевом сбое после фактической отправки, но до подтверждения в базе, повтор возможен: Telegram Bot API не предоставляет ключ идемпотентности для sendMessage.

События проверяются каждую минуту, но точное время появления сообщения на телефоне зависит от сети, планировщика и ОС. Звук нельзя принудительно задать через Bot API: пользователь выбирает его в настройках чата бота (профиль → Уведомления → Звук). Сервер отправляет обычные сообщения с `disable_notification: false`, а не беззвучные. [Telegram: звуки уведомлений](https://telegram.org/blog/notifications-bots), [sendMessage](https://core.telegram.org/bots/api#sendmessage).

Отключение кнопкой в Mini App выключает рассылку после подтверждения сервера. Чтобы остановить worker для всех пользователей: `select cron.unschedule('student-life-notifications');` в Supabase SQL Editor. Секреты и Telegram URL с токеном не выводятся в ответы API или логи приложения.

## Совместимость

Официальный SDK: ready/expand, BackButton, обновление темы и безопасных отступов. В обычном браузере весь локальный интерфейс работает, подключение Telegram недоступно. SDK Telegram и шрифт Google Fonts загружаются по HTTPS; при недоступности шрифта используется системный.

[Telegram Mini Apps](https://core.telegram.org/bots/webapps). Публикация и слияние PR не выполняются автоматически агентом; подключённая к GitHub интеграция Vercel может сама создать preview ветки.
